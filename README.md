# Frame APK Push

## Deutsch

Frame APK Push ist eine Linux-Desktop-App zur Einrichtung von Android-Browsern
auf Steam Frame. Sie verbindet den PC mit dem Headset, prüft und überträgt eine
ARM64-Browser-APK und richtet sie als Steam-/Lepton-Titel ein.

Die App unterstützt Chromium und kompatible Browser bei der Nutzung von WebXR.
Sie verwaltet den Start des Browsers, bietet WebXR- und Controller-Prüfseiten
und kann WebGL-Kontexte für XR vorbereiten. Native Hilfsdateien ergänzen die
Integration mit Lepton.

## English

Frame APK Push is a Linux desktop app for setting up Android browsers on Steam
Frame. It connects a PC to the headset, checks and transfers an ARM64 browser
APK, and configures it as a Steam/Lepton title.

The app supports Chromium and compatible browsers for WebXR. It manages browser
launch, provides WebXR and controller check pages, and can prepare WebGL
contexts for XR. Native helper files extend its integration with Lepton.
